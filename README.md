# Sprig - AI Design Thinking Studio

A web app that guides users through the five stages of design thinking:
Empathize, Define, Ideate, Prototype and Test, with a rule-based AI coach at each stage.

## Structure
- index.html   - page structure and content
- css/style.css - styling (light and dark theme, responsive)
- js/app.js    - app logic, stage tools and AI coach

## Run
Open index.html in any browser. No installation or build step needed.
Or run a local server: `python3 -m http.server 8000` and visit http://localhost:8000

## Deploy
Upload the folder to Netlify, GitHub Pages or Vercel.
